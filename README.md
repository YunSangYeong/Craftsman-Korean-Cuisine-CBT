# Craftsman-Korean-Cuisine-CBT
한식조리기능사

한식조리기능사 필기 학습용 React · TypeScript · Vite CBT. 공식 서비스가 아닙니다.

- 실전 모의시험, 랜덤 문제풀이, 오답 복습, 북마크, 통계, JSON/CSV 로컬 문항 등록과 검수 승인, 기록 백업을 제공합니다.
- 학습 기준 선택 메뉴는 없습니다. 실전에서는 답안 선택 후, 랜덤에서는 채점 후 Space로 다음 문제에 이동합니다. 마지막 시험 문제에서 자동 제출하지 않습니다.
- 시험 중에는 해설을 숨깁니다. 답안 변경과 즉시 저장, 절대 종료 시각, 새로고침 복원, 시간 만료 자동 제출을 지원합니다.
- 작은 화면과 가로 화면 메뉴도 내부 스크롤이 됩니다. 비공식 표시는 푸터/사이드바, 출처와 한계는 문제은행 관리 및 이 문서에 둡니다.

## 시험 규칙 확인 상태

**공식 확인 미완료입니다.** 2026-10-22 Q-Net 종목 페이지 요청은 프록시 `CONNECT tunnel failed, response 403`으로 차단됐습니다.
확인 대상: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7910
원문, 첨부 출제기준, 기출 원문·정답·재배포 조건을 읽었다고 주장하지 않습니다.

현재 [자격증 설정](src/qualification.ts)은 일반적으로 알려진 다음 내용을 **학습용 가정**으로 사용합니다. 공식 자료 대조가 완료된 시험 재현이 아닙니다.

| 항목 | 학습용 설정 |
| --- | --- |
| 자격증 | 한식조리기능사 |
| 통합 과목 | 한식 재료관리, 음식조리 및 위생관리 |
| 형식 | 객관식 4지선다, 60문항 |
| 시간 | 60분 |
| 채점 | 동일 배점, 정답 수/60 × 100, 미응답은 오답 |
| 합격 | 원점수 60점 이상(36개 정답), 과락 없음 가정 |
| 추출 | 통합 무작위, 단원별 공식 출제 비율 재현 아님 |

공식 규정 확인과 최신 법령 수치 대조는 남은 작업입니다. 법정 온도·시간·기준 수치를 임의 작성한 문항은 포함하지 않았습니다.

## 실제 문제은행

**중복 제거 후 등록·내부 검토 60문항 / 목표 1,000문항 / 부족 940문항. 수량 기준 미충족입니다.**

| 구분 | 수 |
| --- | ---: |
| 원문 기출 | 0 |
| 복원 | 0 |
| 자체 제작 개념형 | 60 |
| 숫자 조건 변형 / 변형 family | 0 / 0 |
| 검증 대기 / 오류 제외 / 중복 제외 | 0 / 0 / 0 |
| 위생·안전 / 재료·영양 / 한식조리 | 20 / 20 / 20 |

과목은 위의 통합 1과목이며 세 구분은 학습용 단원입니다. 개인 로컬 등록분은 이 집계에 포함하지 않습니다.
문항은 AI 일반 조리 지식에 근거해 새로 작성했습니다. 읽지 않은 공식 자료나 교재를 정답 증빙으로 인용하지 않았습니다. 저장소 URL은 작성 원고의 위치이며 외부 정답 증거가 아닙니다.

내부 검토는 본문·네 보기·정답·해설의 일치와 명백한 의미 중복, ID와 정규화 본문·보기의 중복을 확인한 범위입니다. `reviewed`는 이 내부 검토 상태를 뜻합니다. 전문가 검수·독립 외부 사실 검증·공식 출제기준 대조 완료를 뜻하지 않습니다. 1,000문항의 충분한 범위와 난이도·정확성을 확보하지 못했으므로 같은 문항의 숫자·문구 변형으로 수량을 채우지 않았습니다. 60개는 한 회 실행을 위한 초기 분량이며 최종 수량 기준의 대체가 아닙니다.

- [원고 및 결정적 생성 코드](scripts/create-bank.py)
- [실제 학습 JSON](src/data/questions-main.json)
- 자체 제작 문항·원고·등록 예제: CC BY 4.0, Korean Cuisine CBT contributors. 외부 기출을 복제하지 않았습니다.
- 재사용 앱 코드: 원본 MIT 고지 보존. 전기 문항과 개인 기록은 복사하지 않았습니다.

## 개발과 검증

Node.js 24.19.0. 현재 체크아웃을 사용하며 별도 worktree는 필요하지 않습니다.

```sh
npm ci --cache /tmp/korean-cbt-npm-cache
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

이 환경에는 `/usr/bin/chromium`이 있어 브라우저 다운로드 대신 다음 검증을 실행했습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

초기 설치는 기본 npm 캐시 디렉터리 쓰기 실패로 중단됐습니다. `/tmp` 캐시를 지정한 `npm ci`가 lockfile과 무결성 검증을 유지한 채 성공했습니다. TLS·체크섬 검증은 끄지 않았습니다.

[검증 기록](docs/validation.md)에 실제 결과와 한계를 기록합니다. Chromium 데스크톱/Pixel 7 에뮬레이션을 사용하며 실기기·Safari·Firefox 검사는 하지 않았습니다.

## 저장과 출처 관리

저장 키는 `korean-cuisine-cbt:v1`입니다. 같은 소유자의 다른 Pages 앱 기록과 분리합니다. 최근 응답 5,000개, 시험 30회를 보관합니다. 손상 원본은 자동 덮어쓰지 않고 저장 실패를 경고합니다. 초기화는 확인을 거치며 기본 문항은 유지합니다. 백업 내보내기만 지원하고 백업 UI 복원 기능은 없습니다. 시크릿 모드·iframe의 저장 제한과 다른 origin에서의 기록 분리에 유의하세요.

등록 문항은 브라우저 로컬에만 저장되며 공용 은행에 자동 게시되지 않습니다. 가져오기는 ID·정규화 본문/보기 중복을 제거하고 검증 대기로 등록합니다. 사용자가 출처·권한·정답 확인과 근거 입력 후 로컬 승인할 수 있습니다.
